# Product Screenshots

These images are browser captures of SmartRoute's real interface using isolated,
synthetic API responses and a Demo workspace. They contain no real account data,
provider keys, or customer conversations. Metrics and model examples are illustrative,
not production benchmarks, verified savings, or endorsements.

The current captures are 1440 x 1600 PNGs from an isolated headless browser. Each
screen is checked for hidden internal scroll content before capture, including the
dashboard's final latency table. Do not use embedded-pane captures or freeze a
short viewport and assume `fullPage` includes nested scroll areas.
